# Dollchan Next privacy notice

Dollchan Next does not contain telemetry, analytics, advertising or remote executable code. Configuration,
filter rules, hotkeys and favourites are stored in Firefox local/sync extension storage.

## Core imageboard traffic

The extension reads imageboard pages and may request updated threads, media and previews from the board. When the
user submits a post, the selected text and files are transmitted to that board. This traffic is necessary for the
extension's primary functionality and is covered by the `personalCommunications`, `browsingActivity` and
`websiteContent` declarations shown by Firefox during installation.

## Optional external services

External media services are disabled by default. If the user explicitly enables them, Dollchan Next may request
public video metadata from YouTube or Vimeo and may open an image-search provider with a selected public media URL.
The provider receives only the data needed for that action. Dollchan Next does not receive analytics or payment
from these providers.

The current optional providers are YouTube, Vimeo, Google Lens, Yandex Images, TinEye, SauceNAO, IQDB and trace.moe.
Consent can be revoked at any time from the extension settings; imageboard tabs must then be reloaded.

## Support

Privacy questions and defects can be reported at https://github.com/qqrm/Dollchan-Next/issues.
